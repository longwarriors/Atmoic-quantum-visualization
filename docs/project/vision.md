# 愿景与边界

## 项目缘起

QuViz 源自一个长期研究愿望：把薛定谔方程从纸面公式变成可计算、可验证、可交互探索的视觉对象。目标并不是收集更多“轨道图片”，而是建立一套能沿下列方向持续扩展的量子可视化实验系统：

- 空间维度：1D、2D、3D，以及多电子的 $3N$ 维配置空间；
- 动力学：定态 TISE 与含时 TDSE；
- 物理对象：复波函数、密度、相位、概率流、期望值与测量分布；
- 化学解释：球谐基、实轨道、点群、SALC、杂化轨道与分子轨道；
- 数值方法：解析解、有限差分、谱方法、采样与实验前向模型。

知乎资料提出的“自己计算、打印中间结果并作图”适合作为学习方法和项目动机，但具体物理结论仍由教材、数学参考、同行评审论文和可复现测试承担证据责任 [@zhihu-molecular-orbital]。

## 统一的问题框架

每个可视化必须完整回答：

$$
\boxed{
\text{State}
\rightarrow
\text{Observable}
\rightarrow
\text{Representation}
\rightarrow
\text{Renderer}
\rightarrow
\text{Measurement model}
}
$$

例如，氢原子 $2p_z$ 是一个状态标签；$|\psi|^2$ 是 observable；点云与等值面是两种 representation；WebGL 是 renderer；光电离显微镜的探测器图样则属于 measurement model。它们不能用“电子云”三个字全部代替。

## 三条长期原则

1. **公式、离散化和画法分层。** 改材质不能冒充改变 observable，换网格也不能悄悄改变物理单位。
2. **科学声明必须可追溯。** 每条关键结论要能追到来源、代码、参数和验证测试。
3. **愿景与现状分开。** 概率流线已经进入当前能力；仍在设计中的 WebGPU、体渲染、节面几何或多电子采样，不得提前写成已有功能。

## 不把什么当成目标

- 不把视觉相似度当成数值正确性的充分证据；
- 不把单次位置样本连成电子的历史轨迹；
- 不把杂化轨道当成唯一、直接可观测的成键实在；
- 不把探测器强度图等同于原空间三维概率密度；
- 不把某篇博客在某台机器上的加速倍数写成项目性能承诺。
