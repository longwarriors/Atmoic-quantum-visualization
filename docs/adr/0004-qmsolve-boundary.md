# ADR-0004：qmsolve 作为参考而非真值内核

- 状态：Accepted
- 日期：2026-08-22

## 决策

不直接 fork qmsolve 作为 QuViz 科学核心。可以参考其 TISE/TDSE 和可视化接口，但网格、边界条件、奇点和简并态分类必须重新建立契约 [@qmsolve, v2.0.0]。

## 证据

审计对象是 release 2.0.0（该仓库唯一的 tag，commit `95d7571`，2024-05-12 发布），不是默认分支 `main` 的当前状态：

- 坐标由 `np.linspace(-extent/2, extent/2, N)` 构造，**包含两端点**，因此相邻样点间距是 $L/(N-1)$；而 `hamiltonian.py` 设 `dx = extent / N`，并把同一个 `dx` 用于动能算子、动量算子、FFT 频率网格和归一化。真正的不一致不是“两处 `dx` 互相矛盾”（它们用的是同一个值，内部自洽），而是 **`dx` 与它所描述的坐标数组不符**；相对误差为 $1/N$，动能项因此带有约 $2/N$ 的偏差（$N=100$ 时约 2%）。这是收敛常数问题，不是定性错误；
- Coulomb 原点通过 $r\leftarrow\max(r,10^{-6})$ 硬截断；
- 奇数网格包含原点时可能制造极深伪态；
- Cartesian 盒会破坏连续旋转对称性并混合简并本征矢。

## 后果

QuViz 从小型、可证明一致的 Grid 对象和解析基准开始，再逐步加入通用求解器。
