# ADR-0004：qmsolve 作为参考而非真值内核

- 状态：Accepted
- 日期：2026-08-22

## 决策

不直接 fork qmsolve 作为 QuViz 科学核心。可以参考其 TISE/TDSE 和可视化接口，但网格、边界条件、奇点和简并态分类必须重新建立契约。

## 证据

上传的 2.0.0 版本中：

- 坐标使用包含两端点的网格，而 Hamiltonian 中 `dx=L/N`；
- Coulomb 原点通过 $r\leftarrow\max(r,10^{-6})$ 硬截断；
- 奇数网格包含原点时可能制造极深伪态；
- Cartesian 盒会破坏连续旋转对称性并混合简并本征矢。

## 后果

QuViz 从小型、可证明一致的 Grid 对象和解析基准开始，再逐步加入通用求解器。
