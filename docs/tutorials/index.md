# 教程

教程按物理对象递进。页面会区分已经验证的实现、原型和目标设计；总状态以[当前状态](../project/status.md)为准。

1. [Phase 0 交互工作流](phase-0-walkthrough.md)：从默认点云到切片、概率流与解析含时叠加态；
2. [氢与类氢轨道](hydrogenic-orbitals.md)：解析波函数、节点和坐标约定；
3. [实轨道与复轨道](real-vs-complex.md)：区分基选择、相位和概率密度；
4. [电子云采样](sampling.md)：独立样本、体积测度与诊断；
5. [点群与轨道杂化](hybridization.md)：当前固定的 $sp^3$ 变换与后续边界；
6. [3D 前端渲染](frontend-rendering.md)：Scene Contract、点云、网格与 GPU 表示。

如果目标是先把当前版本完整跑通，从第 1 篇开始；如果要复核公式或实现约定，按后五篇的主题进入。
