# Phase 0 交互工作流

!!! note "适用范围：Phase 0 checkpoint"

    本页只讲当前源码和界面已经实现、且有自动门禁覆盖的路径。数值 TISE/TDSE、一般叠加态点云采样、独立节面几何、完整点群/SALC 与多电子模型不在 Phase 0 中。能力总表见[当前状态](../project/status.md)。

先按[安装与启动](../getting-started/installation.md)运行源码。开发模式的页面位于
`http://127.0.0.1:5173/`；完成前端构建后，单服务预览位于
`http://127.0.0.1:8000/`。以下步骤在两种入口中的行为相同。

## 1. 读懂默认的 $2p_z$ 点云

页面首次稳定后，顶部状态应显示 $2p_z$，检查器显示“电子云”和点数。默认几何来自

$$
\psi_{210}(r,\theta,\phi)=R_{21}(r)Y_1^0(\theta,\phi).
$$

点不是电子沿时间走过的位置。它们是从 Born 分布
$|\psi|^2\,d^3r$ 独立抽取的位置样本；把点按返回顺序连起来没有物理意义
[@griffiths2018qm, eq. (1.3), p. 4; @tully2013pointillist]。

在“态制备”中切换 $n,\ell,m$ 或实/复基，改变的是量子态；在“表示法”中切换画法，
改变的是同一状态产生的可视资产。必须先保持这两层分开，才能解释屏幕上的图。

## 2. 比较点云与等密度面

1. 在“表示法”中选择“电子云”，观察随机样本如何填充高概率区域。
2. 改选“等密度面”，观察 $|\psi|^2=c$ 的三角网格。
3. 改变“包围概率”后等待新场景完成，不要把旧场景当成新请求的结果。

等密度面只是某个阈值下的 representation，不是唯一的轨道边界。payload 同时报告请求的
包围概率、有限网格捕获质量、实际网格与诊断；数值门禁无法在当前上限内支持某个状态时，
服务会返回有原因的 422，而不是交付一张未经证明的表面。

## 3. 在主平面上检查标量场

选择“平面切片”，然后分别改变：

- “平面”：`xy`、`xz` 或 `yz`，都经过原点；
- “场”：$|\psi|^2$、$\operatorname{Re}\psi$、$\operatorname{Im}\psi$ 或
  $\arg\psi$。

$|\psi|^2$ 使用非负顺序色图；实部和虚部使用以零为中心的发散色图；相位使用周期色相。
相位在振幅太低处没有稳定意义，因此相位切片带有 `valid_mask`。该 mask 只表示“此处相位
不应着色”，**不是**已经提取出的节面证书。

高 $n$ 切片的分辨率下限由服务端根据径向特征计算，并通过 catalog/Scene Contract 交给前端。
即使请求通过最低分辨率检查，也不等于所有高阶细节都已经获得普适收敛证明。

## 4. 用正例与负例理解概率流

默认实基 $2p_z$ 可取为实函数，所以

$$
\mathbf j=\frac{\hbar}{\mu}\operatorname{Im}(\psi^*\nabla\psi)=\mathbf0.
$$

选择“概率流线”时，界面会解释为什么当前结果为空；这不是加载失败。随后点击
“载入并显示概率流示例”，界面从服务端 orbital catalog 载入复基
`3d, m=2`，并请求真实的 current-field 资产。检查器应显示非零流线数和连续性诊断。

流线积分的是 $\mathbf v=\mathbf j/\rho$（只在 $\rho>0$ 且通过密度遮罩处定义），
用来表示概率输运。除非另外明确采用某种解释框架，不应把它称为实验拍到的电子轨迹。

## 5. 区分真正的含时态与简并负控制

回到“态制备”，选择“叠加态”。目录中的预设包含：

- “1s + 2p_z · Bohr 振荡”：不同能量项的相对相位随时间变化；
- “2s + 2p_z · 简并定态”：两项能量相同，用来检验界面不会制造伪运动；
- “1s + 3d_z²”：四极型变化的例子；
- “2p(+1) + 2p(−1)”：简并且可组合成零净流的实轨道负控制。

非简并预设可以用“随 t 演化”推进解析相位。这里没有运行数值 TDSE 求解器：服务直接使用
已知氢样能量令每项获得 $\exp(-iE_kt/\hbar)$ 相位。`period_au=0` 的简并预设不会播放，
因为其密度不应随时间变化。

叠加态当前支持等密度面、切片和概率流；**一般叠加态点云采样仍未实现**。前端只能请求
catalog 和服务端工作量门禁共同声明可服务的参数，不会用客户端猜测替代科学能力判断。

## 6. 遇到 422 时先读原因

Phase 0 对无法在当前计算预算和分辨率内诚实表示的请求采用 fail-closed：

- 量子数、奇偶分辨率或参数域非法；
- 网格不足以解析已知径向特征；
- 有限盒质量或拓扑诊断未收敛；
- 组合请求超过 term-pixel、term-voxel 或流线积分预算；
- 数值尺度超出 float32/float64 可表示范围。

这些 422 是模型边界的一部分，不应通过放宽前端校验或隐藏错误来“修复”。逐端点参数、
响应模型与拒绝条件见 [HTTP API](../reference/api.md)，可导入的 Python 接口见
[Python API](../reference/physics-api.md)。
